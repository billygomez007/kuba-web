# Canonical Drizzle Migration Lineage

This directory is intentionally separate from the immutable legacy `drizzle/`
history. It is the only output directory for migrations created after the
canonical-baseline repair.

- Schema authority: `db/schema.ts`
- Staging credentials: `TURSO_STAGING_DATABASE_URL` and
  `TURSO_STAGING_AUTH_TOKEN`
- Production credential variables are deliberately not supported by
  `drizzle.canonical.staging.config.ts`.

`0000_canonical_baseline.sql` is a Drizzle-generated, non-destructive marker
that was validated on a disposable test clone only. It has not been applied to
the main staging database or production.

`meta/0000_snapshot.json` is a Drizzle-native snapshot generated by
allowlisted introspection of the verified 38-table disposable clone. It excludes
Mastra and `__drizzle_migrations`, and it passed a no-change generation check
against the same introspected baseline schema. Future reconciliation migrations
must be generated and reviewed from `db/schema.ts`; they must never be applied
automatically.
